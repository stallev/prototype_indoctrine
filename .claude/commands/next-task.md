Ты — ведущая сессия мультиагентного пайплайна миграции, описанного в [`docs/multi-agent-workflow.md`](../../docs/multi-agent-workflow.md). Пользователь явно авторизовал полностью автономное прохождение всех задач и всех фаз без промежуточных подтверждений, с автоматическим коммитом после каждой успешно проверенной фазы. `git push` тебе делать **запрещено** при любом исходе — это единственное действие, оставленное пользователю.

## Основной цикл

Повторяй следующие шаги, пока не выполнится одно из условий остановки (см. ниже):

1. Открой файлы [`docs/implementation/`](../../docs/implementation/) по порядку (`phase-9.1-content-migration.md` … `phase-9.5-acceptance.md`).
2. В текущем (первом незавершённом) файле фазы найди первую задачу со `**Статус:** todo`.
   - **Если такая задача есть** — выполни «Цикл задачи» (ниже), затем вернись к шагу 1.
   - **Если задач со `Статус: todo` в файле нет, но есть `in-progress`/`blocked`** — это незавершённая работа: `in-progress` без активного вызова означает прерванный прогон, продолжи с этой задачи как с новой попытки; `blocked` — см. «Остановка по эскалации» ниже.
   - **Если все задачи файла `Статус: done`, а `Статус фазы` ещё не `done`** — выполни «Фазовый контроль» (ниже).
   - **Если `Статус фазы: done` для всех 5 файлов** — см. «Остановка по завершению» ниже.

## Цикл задачи

1. Выставь задаче `**Статус:** in-progress`.
2. Вызови сабагента `implementer` с текстом задачи, `Definition of Done` и `Описание`; при ретрае — дополнительно передай накопленные `Заметки агентов`.
3. Вызови `quality-checker` (свежий контекст) с diff и DoD.
4. Если `quality-checker` вернул `PASS` — вызови `code-reviewer` (свежий контекст) с diff.
5. Если на любой стадии `FAIL`/есть Blockers — увеличь `Попытки`, допиши причину в `Заметки агентов`, вернись к шагу 2 (максимум 3 попытки суммарно на задачу).
6. При успехе всех трёх стадий — выставь `**Статус:** done`, допиши краткое резюме в `Заметки агентов`.
7. При исчерпании 3 попыток — выставь `**Статус:** blocked`, допиши итоговую диагностику в `Заметки агентов` и переходи к «Остановка по эскалации».

## Фазовый контроль (`docs/multi-agent-workflow.md` §5а)

1. Выставь `**Статус фазы:** in-review`.
2. Вызови `quality-checker` (свежий контекст) с расширенной областью: перепроверить **все** Definition of Done всех задач файла фазы целиком — обязательно с нуля `npm run typecheck`, `npm run lint`, `npm run build` (три отдельные команды, все три должны пройти), плюс полный count-parity для 9.1, плюс для фаз с UI — регрессионный браузерный обход всех затронутых фазой маршрутов, не одного.
3. Если `PASS` — вызови `code-reviewer` (свежий контекст) с **полным** накопленным diff фазы (всё, что изменилось с последнего коммита пайплайна).
4. Если обе проверки `PASS`:
   - `git add` файлов, затронутых фазой;
   - `git commit` с сообщением `type(scope): summary` (`scope` = id фазы, например `feat(phase-9.1): контент как TypeScript`), тело — список завершённых задач, плюс обычный `Co-Authored-By` для коммитов Claude Code;
   - **не выполняй `git push`**;
   - выставь `**Статус фазы:** done`;
   - вернись к основному циклу (шаг 1) — переход к следующему файлу фазы автоматический, без подтверждения.
5. Если любая проверка `FAIL` — увеличь фазовый счётчик попыток (отдельный от счётчиков задач), допиши причину в `Заметки агентов` конкретных задач, которые нужно доработать, верни их `Статус: in-progress` и обработай через «Цикл задачи» заново (не всю фазу — только проблемные задачи); максимум 3 фазовые попытки.
6. При исчерпании 3 фазовых попыток — выставь `**Статус фазы:** blocked` (коммита нет) и переходи к «Остановка по эскалации».

## Остановка по эскалации

Выведи пользователю: какая задача/фаза заблокирована, что именно не проходило на каждой попытке (из `Заметки агентов`), и останови цикл (`/loop stop`, если активен). **Не** коммить и не переходи дальше.

## Остановка по завершению

Когда `Статус фазы: done` для всех 5 файлов — сообщи пользователю, что Фаза 9 полностью завершена и закоммичена (по фазам), и что теперь `git push` — на его стороне. Останови цикл (`/loop stop`, если активен).
