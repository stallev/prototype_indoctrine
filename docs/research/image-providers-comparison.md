# Сравнение провайдеров генерации изображений (API)

**Дата обзора:** 21 августа 2026  
**Контекст проекта:** печатные карточки катехизиса (A6 альбом ~148×105), детский тёплый стиль, доктринальные ограничения, **кириллический текст** на лицевой стороне. Сейчас в инструменте: `gemini-2.5-flash-image` через Vercel AI SDK (`@ai-sdk/google`), ~**$0.039**/картинка + входные токены; кириллица накладывается Canvas после генерации.

Документ — ориентир для решения о смене провайдера. Тарифы меняются; перед выбором сверяйте официальные страницы.

### 3.1. Детали по провайдерам

**Google Gemini Image (текущий стек)**  
Плюсы: уже внедрён; `aspectRatio` в `generateImage`; Flash Lite дешевле; Pro — для сложных сцен.  
Минусы: кириллица в кадре; 148:105 нет в enum (маппинг на 4:3); Imagen на API уходит.  
Качество: спокойные, «понятные» сцены; для карточек приемлемо при overlay текста.

**xAI Grok Imagine**  
Плюсы: **$0.02** flat; промпты проекта уже на английском «Scene:» под Grok; до 2K без отдельной доплаты (по докам/обзорам); высокий throughput на standard.  
Минусы: отдельный API/ключ; Pro дороже и с лимитами; кириллица всё равно overlay.  
Качество: часто выигрывает у Flash по «киношной» / живописной картинке — близко к целям колоды.

**OpenAI GPT Image**  
Плюсы: лучшее следование инструкциям и лат. тексту; Batch −50%; экосистема.  
Минусы: high дорогой; биллинг токенами (промпт+правки дорожают); overkill, если текст всё равно Canvas.  
Качество: топ для «сделай ровно как сказано»; стиль может быть «чище/студийнее», не обязательно теплее Grok.

**Flux (BFL / fal / Replicate)**  
Плюсы: цена и фотореализм; klein/schnell — массовая генерация.  
Минусы: другой «язык» промптов; контроль доктрины (одежда, отсутствие Божества) нужно жёстче тестировать; нет единого «детского» defaults.  
Качество: сильный реализм; для сказочно-плоской детской карточки может потребоваться style prompts / LoRA / post.

**Ideogram**  
Плюсы: если когда-нибудь понадобится **латинский** текст внутри кадра.  
Минусы: кириллица не решает проблему; цена не ниже Grok standard существенно.  
Для текущей колоды с Canvas-overlay — низкий приоритет.

**Midjourney / подписки**  
Слабо подходят как backend API продукта (лицензии, автоматизация, биллинг).

## 4. Критерии выбора именно для карточек катехизиса

1. **Кириллица** — не критерий выбора модели: оставлять **post-overlay** (Arial, `#FF8C00`).  
2. **Стоимость × ретраи** — при 114 × 2–3 попытки Grok $0.02 или Flux ~$0.01 выгоднее Gemini $0.039.  
3. **Стиль промптов** — файл `prompts/grok-card-prompts.md` уже заточен под Grok; смена на Grok API = меньше переписывания Scene.  
4. **Доктрина** — нужны выборочные прогоны чувствительных номеров (§7 svg-спеки); дешёвые open-weight чаще «ломают» модесть / добавляют лишние фигуры.  
5. **Интеграция** — смена провайдера = новый ключ, контракт `POST /api/image-generator`, правка `route.ts` / AI SDK provider, обновление оценки стоимости в UI.  
6. **Юридическое** — коммерческое использование, watermark (SynthID у Google, C2PA у OpenAI), политика контента.

## 5. Сценарии решения

### A. Остаться на Google, удешевить  
Переключить модель на **`gemini-3.1-flash-lite-image`** (~$0.034). Минимум кода, тот же SDK. Минус: качество/стиль могут чуть уступить 2.5 Flash Image — нужна выборка из 10–15 карточек.

### B. Перейти на xAI Grok Imagine (наиболее логично по контенту)  
`grok-imagine-image` @ **$0.02**. Совпадает с происхождением промптов. Нужен `XAI_API_KEY`, адаптер вместо/рядом с Google, проверка aspect ratio API. Оценка стоимости UI — обновить константы.

### C. Дешёвый объём (черновики) + дорогой финал  
Черновики: Flux Schnell / fal ~$0.005. Финал: Grok Pro / GPT medium / Gemini Flash. Два маршрута в UI («черновик» / «печать»).

### D. Максимум качества инструкции  
GPT Image medium/high или Gemini 3 Pro Image — если ретраи по сцене дороже экономии на дешёвой модели.

## 6. Риски и ограничения исследования

- Цены и имена моделей (**GPT Image 2**, **Nano Banana 2**, **Flux 2**) быстро меняются; часть цифр из вторичных обзоров — сверять с официальными прайсами.  
- «Качество» субъективно; для колоды нужен **A/B на 10–20 одинаковых Scene** (с Canvas-текстом).  
- Anthropic **не** предлагает аналог image-generation API для этой задачи (на момент обзора).  
- Batch-скидки снижают $/image, но усложняют синхронный UX генератора.

## 7. Практическая рекомендация

Для смены провайдера **в первую очередь рассмотреть xAI Grok Imagine standard ($0.02)** — дешевле текущего Gemini, стилистически ближе к уже написанным промптам, простой flat billing.  
**Запасной дешёвый путь внутри Google:** Flash Lite Image.  
**Кириллицу** по-прежнему не отдавать модели — только overlay.

Перед финальным выбором: прогнать одни и те же 10 Scene (в т.ч. чувствительные §7) на Gemini Flash / Grok Imagine / (опционально) Flux klein и сравнить глазами под одинаковым Canvas-текстом.
